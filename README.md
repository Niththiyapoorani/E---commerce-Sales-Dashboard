# E---commerce-Sales-Dashboard
An interactive E-commerce Sales Dashboard in Power BI to track and analyze sales.

  -------------------

## Insights

 -	Identifying top-performing **states and categories**
 -	Analysing monthly **profit trends**
 -	Comparing **sales volume by category** against profit margins
 -	Understanding customer purchasing patterns through **payment modes**

  --------------------

 ## Dashboard Layout

  - Title: **'E-commerce Sales Dashboard'** at the top.
  - KPI Cards: Total Sales, Total Profit, Quantity Sold, and Average Order Value (AOV).
  - Quarter Slicer for **time-based filtering**.
  - Visualizations: 
       * Bar Chart: Profit by Month. 
       * Horizontal Bar Chart: Sales by State.
       * Donut Charts: Quantity by Category and Payment Mode Distribution.
       * Stacked Column Chart: Sales by Customer.
       * Horizontal Bar Chart: Profit by Sub-Category.

   --------------------

   ## Tool used

   - Microsoft PowerBI
   - Slicers
   - Filters

  ## Interactivity and final Touch

   - Drill-downs enabled for Category → Sub-Category and State → City.
   - Customized tooltips show additional details on hover.
   - Filters and slicers dynamically update all visuals.
   - Data validation performed to ensure accuracy of results.

  ## Conclusion

  The E-commerce Sales Dashboard in Power BI provides a comprehensive and interactive way to monitor business performance.
